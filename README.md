## 🎯 О проекте

Интеллектуальный чат-бот с **агентной архитектурой**, который:
- ✅ Отвечает на вопросы по машинному обучению на русском языке
- ✅ Использует векторный поиск для нахождения релевантной информации
- ✅ Работает через Telegram бота и REST API
- ✅ Поддерживает контекст диалога с автоматической суммаризацией
- ✅ Использует ReAct агента для принятия решений о вызове инструментов

**База знаний**: 69 статей из учебника Яндекса по ML, разбитых на векторные эмбеддинги.

## 🧩 Компоненты проекта

### 1️⃣ **AgenticRAGSystem** (`src/rag_system.py`)
Ядро системы с агентной архитектурой:
- **ReAct Agent**: Принимает решения о вызове инструментов на основе промпта
- **Инструмент поиска**: `retrieve_tool` для векторного поиска в Qdrant
- **Управление контекстом**: Автоматическая суммаризация длинных диалогов
- **Rate limiting**: Защита от превышения лимитов API (70 сек между запросами)

### 2️⃣ **REST API** (`src/api.py`)
FastAPI сервер для обработки HTTP-запросов:
```
POST /query
{
  "question": "Что такое градиентный спуск?",
  "user_id": "user123"
}
```

### 3️⃣ **Telegram Bot** (`src/bot.py`)
Асинхронный бот для взаимодействия с пользователями:
- Команды: `/start`, `/help`
- Обработка текстовых сообщений
- Разбиение длинных ответов (лимит Telegram: 4096 символов)

### 4️⃣ **Data Loading** (`data_loading/html_loader.py`)
Скрапер для загрузки статей:
- Selenium для рендеринга JavaScript
- Автоматический сбор всех статей с главной страницы
- Сохранение маппинга URL ↔ файл

### 5️⃣ **Evaluation** (`evaluation/evaluate_rag.py`)
Автоматическая оценка качества RAG системы с использованием LLM-as-a-Judge подхода:
- **Answer Quality Score**: Оценка качества финального ответа (1-5)
- **Категоризированное тестирование**: 7 типов вопросов (базовые, продвинутые, сравнительные, с подвохом и др.)
- **Детальная статистика**: Средняя оценка 4.83/5 на 29 тестовых запросах

## 📊 Оценка качества

Система автоматической оценки RAG (`evaluation/evaluate_rag.py`) использует **LLM-as-a-Judge** подход с моделью **openai/gpt-oss-120b** (GROQ API):

### Метрика

**Answer Quality Score** (1-5) - Оценка качества финального ответа по критериям:
- 1 - не отвечает на вопрос
- 2 - частично отвечает, много неточностей
- 3 - отвечает, но неполно или с ошибками
- 4 - хорошо отвечает, минимальные недочеты
- 5 - отлично и полно отвечает на вопрос

### Результаты оценки

**Общая статистика** (29 тестовых запросов):
**Средняя оценка качества ответов: 4.83/5**

**По категориям запросов:**
- **Базовые вопросы** (6 запросов): 4.83/5
- **Продвинутые вопросы** (5 запросов): 4.8/5
- **Сравнительные вопросы** (3 запроса): 5.0/5
- **Контекстные вопросы** (4 запроса): 5.0/5
- **Граничные случаи** (3 запроса): 5.0/5
- **Вопросы с подвохом** (4 запроса): 5.0/5

### Запуск оценки

```bash
cd evaluation
python -m evaluation.evaluate_rag
```

Результаты сохраняются в `evaluation_results.json` с детализацией по каждому запросу.

## 🔧 Дополнительная информация

### Особенности агентной архитектуры

- **ReAct Prompting**: Агент самостоятельно решает, когда использовать векторный поиск
- **Контекстная память**: Автоматическая суммаризация истории диалога
- **Smart Chunking**: Фрагменты текста оптимизированы для эмбеддингов (512 токенов)
- **Rate Limiting**: Защита от превышения TPM лимитов GROQ API

### Промпты системы

Все промпты хранятся в `src/prompts.yaml`:
- `ReActPrompt` - инструкции для агента
- `DialogSummaryPrompt` - правила суммаризации

### Прокси для GROQ API

Если GROQ API недоступен в вашем регионе, система использует HTTP прокси (настраивается в `.env`).
